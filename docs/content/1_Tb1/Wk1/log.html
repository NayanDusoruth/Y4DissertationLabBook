Reading notes: Second quantisation impressions (Altland and Simons 2010):

Second quantisation seems to be general framework of ladder operators and associated commutation relations; which is a familiar concept. Apparently generalises nicely to N-body quantum physics.

Chapter motivates second quantisation by highlighting computational issues w/many body QM due to indistinguishablity, symmetrization.antisymmetrization, and the exchange of particle numbers.

Second quantisation basics

It then covers the “apparatus of second quantization”.

Compares representation of labelling particles in state individually to simply counting the number of particles in each state (I.E \(\ket{1, 1, 1, 1, 2, 2, 3}\) becomes \(\ket{4, 2, 1}\)). This is the “occuptation number representation”. Also note the “Fock space” \(\mathcal{F}\); made up of basis states \(\{ \ket{n_{i}} \}\) w/out occupation num condition \(\sum n_i = N\). Therefore many body state can be represented as \(\ket{\Psi}=\sum_{n_{i}} c_{n_i}\ket{n_{i}}\).

Within this framework, ladder operators can be constructed to act on \(\mathcal{F}\):

\(a_{i}^{\dagger}\ket{n_{1},...,n_{i},...}=(n_{i}+1)^{1/2}\zeta^{s_{i}}\ket{n_{1},...n_{i}+1,...}\) \(s_{i}=\sum_{j=1}^{i-1}n_{j}\)

Note that in the fermionic case, the \(n_{i}+1\) operation is a mod 2 operation \(n_{i}+1 \equiv (n_{i}+1)\%2\) Utility of this; can generate all states by repeated application of \(a_{i}^{\dagger}\) to vacuum state:

\(\ket{n_{1},...}=\prod_{i}\frac{1}{(n_{i}!)^{1/2}}(a_{i}^{\dagger})^{n_{i}\ket{0}}\)

Wierd notation used by chapter for commutation/anti-commutation relations:

\([A,B]_{\zeta}=AB-\zeta AB\)

\([A,B]_{\zeta=+1}=[A,B]_{+}=AB-AB\) // commutator

\([A,B]_{\zeta=-1}=[A,B]_{-}=AB+AB=\{A,B\}\) // anticomutator

Note that:

\([a_i,a_j^{\dagger}]_{\zeta}=\delta_{ij}\)

\([a_i,a_j]_{\zeta}=0\)

\([a_i^{\dagger},a_j^{\dagger}]_{\zeta}=0\)

practical aspects:

The chapter continues into the “practical aspects” of this framework.

NoteSingle particle base transforms

Firstly; switching between single particle bases \(\{ \lambda \} \to \{ \widetilde{\lambda} \}\) - the operators transform as:

\(a_{\widetilde{\lambda}}^{\dagger} = \sum_{\lambda}\braket{\lambda|\widetilde{\lambda}}a_{\lambda}^{\dagger}\)

\(a_{\widetilde{\lambda}} = \sum_{\lambda}\braket{\widetilde{\lambda}|\lambda}a_{\lambda}\)

where \(\lambda\) represents a particular particle state in a particular single particle basis. For continuous quantum numbers (I.E, pos) the sum becomes integrals as:

\(a_{\lambda}=\int_{0}^{L}dx\braket{\lambda|x}a(x)\)

\(a(x)=\sum_{k}\braket{x|\lambda}a_{\lambda}\)

NoteSingle particle operators

Secondly operators acting on single particles w/single party operator \(o_{n}\) on nth particle typically become \(\mathcal{O_{1}}=\sum_{n=1}^{N}o_{n}\).

Typical example noted is momentum: \(T=\sum_{n}\frac{p_{n}^2}{2m}\)

Also introduces “occupation number operator” which counts #particles in state:

\(n_{\lambda}=a_{\lambda}^{\dagger}a_{\lambda}\)

Which is useful for actually constructing \(\mathcal{O_{1}}\). Given \(o=\sum_{i}o_{\lambda_i}\ket{\lambda_i}\bra{\lambda_i}\), \(o_{\lambda_i}=\braket{\lambda_i | o | \lambda_i}\). Skipping over details i’m uninterested in rn, the general result is:

\(\mathcal{O_1}=\sum_{\mu\nu}\braket{\mu |o|\nu}a_{\lambda}^{\dagger}a_{\lambda}\)

The chapter then goes into concrete examples to cement these ideas - not immediately relevant, but earmarking p48 in case useful for later.

The simulation assumes no initial correlations; therefore initial correlation matrix is diagonalised and filled with \(\mathcal{f}(\beta, \mu, E)\) for all corresponding system and bath sites:

\(C_{ii} = \mathcal{f}(\beta, \mu, E_i)\)

Third code block sets up this initial correlation matrix.

Sixth/seventh code block builds unitary time evolution:

\(U(t) = e^{-iHt}\)

And build function to evolve correlation matrix over time t. ::: {.column-margin} Sidenote; another julia syntax note; matrix complex conjugate is indicated as H' :::

Code blocks 10, 11 compute and plot the reduced density matrix element corresponding to the occupation of the system. Recalling (Turci 2026), the reduced density matrix follows:
